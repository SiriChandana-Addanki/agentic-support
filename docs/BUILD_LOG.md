## 2026-10-04 — interchangeable LLM planner

Recorded the pre-change reference at `reports/deterministic_baseline_2026-10-04.json` (114/114 strict rows, 38/38 stable tickets, 19 tests at commit `2c36765`). Stock checks and replacement execution now rely on store stock state, and replacement evidence must match the ticket attachment manifest.
